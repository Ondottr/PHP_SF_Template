# PHP_SF_Template v4.0.0

## Highlights

Major version bump aligning the template with the PHP 8.5 / Symfony 8.1 baseline and the
php-simple-framework v4 line.

## Requirements

- **PHP 8.5** (was 8.3)
- **Symfony 8.1** components (was 7.4)
- **php-simple-framework ^4.0**
- **php-sf-cache ^3.0**

## Symfony 8.1 upgrade

- All `symfony/*` dependencies bumped from `^7.4` to `^8.1`.
- **doctrine-bundle 3.x** (from 2.x). Removed the obsolete proxy config options
  (`auto_generate_proxy_classes`, `enable_lazy_ghost_objects`, `proxy_namespace`) in favour of
  `enable_native_lazy_objects`.
- Removed `symfony/proxy-manager-bridge` (deprecated, no longer required) and
  `composer/package-versions-deprecated`.

### Code changes for Symfony 8 removals

- `App/Command/LoadDataFixturesDoctrineCommand`: `#[TaggedIterator]` → `#[AutowireIterator]`;
  replaced the removed `DoctrineCommand::getEntityManager()` with
  `getDoctrine()->getManager()`, typed as `EntityManagerInterface`.
- `ExampleSymfonyController` and the staging overlay CRUD controllers:
  `Symfony\Component\Routing\Annotation\Route` → `Symfony\Component\Routing\Attribute\Route`
  (the `Annotation` namespace was removed in Symfony 8).
- Doctrine routing resources migrated from `.xml` to `.php`
  (`errors.php`, `wdt.php`, `profiler.php`).

## v4 removals (from php-simple-framework)

This release requires **php-simple-framework ^4.0**, which removes:

- `/api/` URL-prefix API detection — declare API endpoints with `#[RouteApi]`.
- `{$param}` URL parameter syntax — use `{param}`.
- `Middleware::changeHeaderTemplateClassName()` / `changeFooterTemplateClassName()`.
- The `TranslatablePropertyName` attribute.

## Other

- PHPStan baseline regenerated for the new Symfony 8.1 / PHP 8.5 error landscape.
- `migrations (?)` marked optional in `phpstan.neon` (directory generated by `init.sh`).
- `bin/console` now wires `setApplicationUserClassName(User::class)`, keeping the three
  entry points in sync (matching `public/index.php` and `tests/bootstrap.php`).

## Upgrade notes

See the php-simple-framework v4.0.0 release notes for details on the removed features and
migration steps. If you relied on the `/api/` URL prefix or `{$param}` syntax, add
`#[RouteApi]` / switch to `{param}` before upgrading.
